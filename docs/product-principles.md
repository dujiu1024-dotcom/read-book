# 产品原则与功能边界

## 1. 最高原则
> 用户通过与 Agent 对话来读书。Agent 不管理阅读过程，只参与阅读和思考。
用户决定何时阅读、何时发言、何时继续。任何功能都不得把用户变成被监督、被考核或被催促的对象。

## 2. 产品定位与核心阅读方式
知行不是电子书阅读器、读书管理工具或学习计划工具，而是以书籍原文为基础、以长期对话为核心交互的阅读产品。
- 原文是阅读主体，AI 解释和整理是辅助。
- 按作者原有章节结构和论述逻辑推进，按语义完整性拆分论述单元，不按固定字数机械切割。
- 用户先阅读原文，再自行理解、复述、提问、质疑或联系现实。
- 一个论述单元展示完成后，Agent 等待用户发言，不主动推送问题、测验、提醒或下一段原文。
- 用户主动表达后，Agent 根据内容回应、启发和讨论；不打分、不考试、不判断用户是否理解达标。
- 用户可以重新展示已读原文，也可以临时查看其他章节或后续内容；临时查看不改变主线位置。
- 允许用户沿自己的思维链适度发散，Agent 在讨论自然收束时帮助回到作者当前论述。
- 不允许跳过主线节点。用户已理解的内容可以简要交流后略读，但仍需经过该主线单元。
- 全书所有主线章节和论述单元均已展示并完成用户侧讨论后，本轮才算完成。
- 一书一个长期 Thread；二刷、三刷仍在同一 Thread 中累积。

## 3. 用户端
### 3.1 书城与书架
- 书籍唯一入库途径为管理员上传、加工和发布。
- 用户加入书架时绑定具体 BookRevision，并获得该版本永久访问权。
- 新版作为独立版本/独立书目，用户需要单独加入；旧版本权益不自动迁移到新版。
- 商城下架不影响已获得的版本访问权。
- 移出书架仅隐藏书架关系，不删除访问权益、Thread、Message、Note、Memory 或历史引用；重新加入同一版本恢复原关系。

### 3.2 阅读与讨论界面
- 页面分为原文区和讨论区：原文位于上方，可折叠；讨论位于下方。
- 用户讨论时可以重新展开原文，确保始终能查看当前讨论依据。
- 原文展示记录与用户讨论属于同一条思维过程，应能互相追溯。
- 不提供选中文字提问、独立阅读器或阅读进度管理。
- 原文展示完毕后等待用户发言；用户没有发言时不主动打断。
- 用户可主动要求继续、复习或临时查看其他内容。

### 3.3 阅读轮次
- 一轮阅读必须完成全书所有主线章节和论述单元的展示与讨论。
- 复习和临时查看不改变主线位置，不创建新轮次。
- 本轮完成后可以询问用户是否开启下一轮，不自动开启。

## 4. 管理端
管理员工作台负责书籍上传、元数据和版本管理、原文解析、全书知识加工、质量报告、异常修正、发布和上下架。
管理员默认不得查看用户私人聊天、原始观点、笔记和认知记忆。

## 5. Agent 规范
第一版只有一个默认阅读 Agent。多角色模式暂缓。
Agent 负责理解原文和全书关系、回应用户问题与质疑、启发讨论、区分作者原文与 AI 推演，并在用户主动要求时继续主线。
Agent 不主动推送问题或学习任务，不催促，不打分，不考试，不自动跳过主线。

## 6. 长期对话与记忆
- 一本具体书籍版本对应一条长期 Thread；所有阅读轮次共用该 Thread。
- 原始聊天消息、原文展示记录、临时查看记录和阅读轮次长期保存。
- 上下文压缩只影响模型调用时携带的上下文，不删除原始数据。
- AI 生成的摘要、笔记和记忆均为派生数据，不能替代原始消息。
- 用户表达、作者观点和 AI 观点必须区分。

## 7. 自动读书笔记与认知演变
- Agent 自动识别有认知价值的表达并沉淀，不设置收藏动作。
- 讨论频率和篇幅是信号但不是唯一标准；简短但重要的独立观点、问题、冲突和判断也应识别。
- 认知演变保留新旧观点，区分补充、修正、冲突、推翻和延伸；不覆盖旧观点。
- Agent 不得仅凭措辞差异擅自断言用户已经改变立场。
- 笔记和记忆保留原始消息、书籍版本、章节/论述单元、时间和阅读轮次来源。
- 用户可以编辑、删除笔记；AI 不得静默覆盖用户编辑。

## 8. 书籍版本与访问权益
- BookRevision 是访问权益和历史引用的版本边界。
- 加入书架时绑定具体 BookRevision；同一作品的新版本需要单独加入。
- 新版不覆盖旧版，不迁移旧版 Thread、Citation 或访问权益。
- 商城可见状态、版本发布状态和用户访问权益独立管理。
- 移出书架只隐藏书架条目，不删除既有访问权益及历史数据。

## 9. 用户数据所有权与存储
- 用户个人阅读数据以用户设备本地存储为主，服务器仅保存加密备份。
- 本地数据包括原始对话、原文展示记录、阅读轮次、笔记、认知记忆、书架和用户设置。
- 换账号不自动迁移、合并或同步旧账号数据；需要时通过备份下载流程恢复到本地。
- 账号注销只删除账号身份和认证关系，不级联删除本地数据或服务器备份。
- 管理员默认不能读取用户私人数据。
- 云端模型调用可能接收当前讨论所需的最小上下文，必须明确告知用户。
- 详见 [本地数据、加密备份与账号分离](data-storage-security.md)。

## 10. 第一版非目标
- 多角色 Agent。
- 主动教学、自动提问、考试、评分和阅读提醒。
- 多设备实时数据同步或账号间自动迁移。
- 在未验证目标平台能力前冻结具体客户端框架或本地数据库。
