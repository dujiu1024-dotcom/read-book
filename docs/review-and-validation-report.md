## 3. 小程序平台技术核查（历史调研；不属于第一阶段放行条件）

### MINI-001：小程序本地存储不能简单等同于 SQLite

已查到的资料显示：

- wx.setStorage 的键值缓存上限为单 key 1 MB、总量 10 MB，不适合作为 Thread/Message/Note/Memory 的完整主数据库。
- 小程序文件系统提供独立的本地用户文件目录，可由 FileSystemManager 读写；腾讯云文档记载本地缓存文件与本地用户文件合计上限为 200 MB。
- 本地文件按微信用户和 appId 隔离；知行自己的多账号切换仍需在数据模型和目录/数据库层显式隔离。
- 文件存储具备持久化能力，但容量有限；大量书籍原文不宜默认全部下载到本地，应按需缓存并明确容量管理。

参考：
- https://intl.cloud.tencent.com/zh/document/product/1219/61747
- https://intl.cloud.tencent.com/zh/document/product/1219/68028

### MINI-002：SQLite WASM 有候选实现，但尚未达到可选型证据标准

候选方向：
- weapp-sqlite：通过 SQLite WASM 和小程序文件系统提供本地持久化，当前项目页面标注为测试版；Web 与微信开发者工具有自动验收，微信真机仍待验证。
- 另有小程序 SQLite/RxDB 适配器处于实验阶段，公开说明提到整库内存缓冲、约 10 MB 适用规模，以及缺少可靠 fsync/文件锁/崩溃恢复承诺等限制。

当前判断：
- SQLite WASM 是值得做 PoC 的候选，不是已验证可用的技术选型。
- 不能只验证“能打开数据库、能查一行”；必须验证事务、并发写、应用强制退出、文件落盘、备份快照、恢复、迁移、容量和长文本性能。
- 必须在微信开发者工具与至少一台真实 iOS/Android 微信环境分别测试；开发者工具通过不能替代真机证据。

参考：
- https://weapp.dev/（项目目录将 weapp-sqlite 标注为测试版，微信真机待验证）
- https://sqlite.weapp.dev/
- https://www.npmjs.com/package/@aiao/rxdb-adapter-miniprogram

### MINI-003：网络和流式输出有技术路径，但必须采用服务端独立任务

资料核查结论：
- 小程序网络接口受服务器域名白名单、HTTPS/WSS、ICP备案和并发数限制。
- 腾讯云整理的微信小程序网络文档记录 wx.request、wx.uploadFile、wx.downloadFile 最大并发为 10；小程序进入后台后，未及时结束的请求可能被中断。
- 已有项目验证记录指出 wx.request 的 enableChunked / onChunkReceived 可用于接收分块，但这不是浏览器原生 EventSource；仍需处理 UTF-8 增量解码、SSE 帧边界、心跳、代理缓冲、后台挂起和断线恢复。

当前判断：
- 小程序流式输出“有实现路径”，不等于已在目标账号和真机通过。
- 正确性必须依赖服务端生成任务独立运行、消息先落库、客户端断线后查询最终状态；token 级实时输出只能是可降级体验。
- 需要验证域名、TLS、反向代理/CDN、首包时间、后台中断、重连和最终结果查询。

参考：
- https://wdk-docs.github.io/wxadev-docs/framework/ability/network.html
- https://intl.cloud.tencent.com/zh/document/product/1219/61745

### MINI-004：H5 阅读器路线受业务域名和主体资质约束

腾讯云小程序文档给出的 H5 文档预览接入方式要求配置业务域名；生产发布需要具备相应小程序主体和业务域名配置。当前项目尚未取得实际小程序账号/主体资质证据，因此不能认定 web-view + H5 阅读器路线已具备上线条件。

参考：
- https://cloud.tencent.com.cn/document/product/436/122402

## 8. 平台路线修订（2026-11-13）

用户已确认第一阶段先使用 PC 浏览器 Web，界面采用接近小程序的窄屏、单列阅读布局；当前不开发小程序。此前第 3 节 MINI-001 至 MINI-004 的资料仍可作为未来小程序适配参考，但不再属于第一阶段技术验证或放行条件。

第一阶段验证范围调整为：
- PC Web 窄屏布局与响应式容器。
- IndexedDB 与 SQLite WASM + OPFS 的本地持久化对比。
- 浏览器文件导入、EPUB 阅读、定位与引用回跳。
- Web Crypto API、端侧密钥管理、加密备份与恢复。
