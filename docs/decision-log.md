# 决策记录

记录产品讨论中已经明确的原则与尚待验证的事项。新决策追加记录，不静默覆盖历史。

## 已确认

### D-001：产品核心原则
- 状态：已确认
- 决策：用户通过与 Agent 对话来读书；Agent 不管理阅读过程，只参与阅读和思考。
- 影响：不做进度管理、阅读计划、打卡、提醒、自动续读等驱动机制。

### D-002：用户端与管理端边界
- 状态：已确认
- 决策：用户端只有手机端；PC Web 仅供管理员使用。
- 用户端入口：书城、书架、对话、我的。

### D-003：一本书一个长期对话
- 状态：已确认
- 决策：一本书对应唯一长期对话，不因章节或主题变化自动新建会话；原始聊天记录长期保存。

### D-004：默认单 Agent
- 状态：已确认
- 决策：第一版只有一个默认阅读导师 Agent，能力根据对话意图自然切换。

### D-005：本地初加工 + 云端完整处理
- 状态：已确认
- 决策：本地可进行初步解析、清洗、元数据提取和可选预切片/预向量化；云端必须保留完整解析、OCR、校验、正式切片、向量化、索引构建与更新能力。
- 约束：本地处理结果不是云端最终结果；云端是正式数据的权威来源。

## 变更规则

任何核心原则变更都应记录：变更原因、影响范围、迁移策略和确认时间。讨论中的假设不得写成已确认决策。


### D-015：云端权威数据 + 本地 SQLite 缓存
- 状态：已确认
- 决策：知行采用云端权威数据模式。手机 SQLite 用于缓存、离线查看、草稿和待同步操作，不作为用户、Thread、Message 和读书笔记的唯一正式存储。
- 原因：需要长期保存、多设备访问、换机恢复、私人数据隔离和笔记来源追溯。
- 约束：本地编辑可先落 SQLite 再同步；同步冲突不得静默覆盖用户修改。

### D-016：本地书籍加工 + 云端自动验收返工
- 状态：已确认（方案原则）；具体验收阈值待测试
- 决策：建设本地书籍加工工具，完成初加工后可一键上传；云端创建独立版本并自动监测/验收。不合格时返回结构化问题报告，本地按失败阶段定向重做；合格后进入正式入库候选，版权审核后才上架。
- 关键约束：云端必须保留完整重新解析、OCR、切片、向量化和索引构建能力；每次加工版本不可变，保留原始文件与处理记录。
- 说明：本地加工工具优先面向管理员 PC 工作流，不要求普通手机用户安装。
