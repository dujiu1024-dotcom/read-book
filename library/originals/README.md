# 原文文件

此目录只存放已核验许可、可合法复制并已取得原始文件的书籍原件。

## 当前状态

本轮完成了书源核验和书目元数据登记，尚未上传任何 PDF/EPUB 二进制原件。不要将本目录的空缺误认为原文已采集。

## 入库要求

每本书独立目录，建议结构：

```
library/originals/<book-id>/
  original.pdf 或 original.epub
  SOURCE.md
  LICENSE.txt（如适用）
  SHA256SUMS
```

SOURCE.md 至少记录作者、书名、版本、语言、出版社、ISBN/DOI、原始下载地址、下载日期、许可名称与链接、第三方素材限制、文件 SHA-256 和文件大小。

CC BY-NC-ND 内容仅可在许可允许的范围内原样分享，不得改编；CC BY 内容如有格式转换或文本抽取，必须保留署名、许可链接并标注修改。仅标记 Open Access 而未确认具体许可的内容，不得复制入库。
