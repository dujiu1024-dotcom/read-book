# PoC B：端侧加密备份、恢复与清除墓碑

独立 PoC，不依赖 PoC A，不接入真实账号、真实用户数据或生产备份 API。

## 启动与测试

```bash
cd poc/encrypted-backup
npm install
npx playwright install chromium
npm run dev
npm test
npm run build
```

## 已实现

- 每个数据集随机生成 256-bit DEK；随机生成独立 256-bit 恢复密钥。
- 使用 AES-256-GCM 包装 DEK 与加密数据块；每块使用随机 96-bit nonce。
- AAD 绑定 dataset_id、backup_id、sequence、chunk_index、schema_version 和算法套件。
- Manifest 只包含协议字段、密文哈希、块大小、父备份 ID 和被包装的 DEK。
- Mock 服务端只保存密文和 Manifest，无解密接口。
- Manifest 明确区分 full/incremental；增量备份必须引用同数据集、紧邻序号的已提交父备份。
- AAD 绑定父备份 ID 与备份类型，篡改父链元数据会导致 AEAD 校验失败。
- 模拟上传会话、分块上传、缺块查询、断点续传、相同分块幂等重传、冲突分块拒绝、提交校验、幂等 init 和清除墓碑优先判定；服务端固定 Manifest 快照并校验分块索引连续、数量一致和 nonce 唯一。
- 新增授权模型：数据集范围绑定、upload/download scope、过期时间、主动撤销；上传初始化、分块、缺块查询和提交通过授权入口校验。
- 新增短时下载票据：下载票据有独立过期时间；清除墓碑同时撤销该数据集的授权、下载票据、备份、上传会话和幂等引用。
- 自动化覆盖备份往返、密文篡改检测、清除后旧备份不可访问、错误恢复密钥、多分块、服务端密文哈希校验、全量到增量父链、父链缺失/跨数据集/序号错误、父链元数据篡改、清除/上传完成竞态、授权范围不足/过期/撤销、下载票据过期和墓碑撤销。

## 关键限制（不得误读为安全验收）

- 当前是浏览器内存 Mock API，不是独立服务进程；断点续传和重复分块语义已在内存模拟层测试，真实 HTTP 上传会话、服务端持久化、跨进程恢复和网络中断仍未完成。
- 当前增量测试只验证元数据父链和增量负载加密，不是数据库级差异计算；完整检查点生成策略、父链压缩/清理与多级恢复仍未完成。
- 恢复凭证是随机高熵密钥的 Base64 展示，不是最终用户友好恢复口令；KDF、恢复凭证格式和密钥生命周期待安全评审。
- 新增的授权与下载票据目前是 Mock Server 内存状态，不是真实身份认证、服务端会话或对象存储预签名 URL；HTTP 鉴权中间件、真实 URL 撤销和跨进程撤销传播仍未完成。
- 晚到上传请求的墓碑优先逻辑已有内存竞态测试；真实网络延迟、服务端持久化事务与多实例一致性仍未完成。
- 错误恢复凭证、父链断裂的多级恢复、服务端日志脱敏和真实网络故障注入仍需继续验收。
- Mock 服务端数据存在内存中，刷新页面后会丢失；不代表持久化实现。
- 本 PoC 只提供算法和状态语义验证起点，不能替代密码学审查、威胁建模或正式安全评审。
