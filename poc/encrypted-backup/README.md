# PoC B：端侧加密备份、恢复与清除墓碑

独立 PoC，不依赖 PoC A，不接入真实账号、真实用户数据或生产备份 API。当前包含浏览器端加密客户端、独立 Node HTTP Mock Server 和文件系统持久化夹具。

## 启动与测试

```bash
cd poc/encrypted-backup
npm install
npx playwright install chromium
npm run dev
npm test
npm run build
```

`npm run dev` 同时启动本地 HTTP Mock Server 与 Vite 页面。默认服务端数据目录为 `.poc-backup-data`，可通过 `POC_BACKUP_DATA_DIR` 修改；端口可通过 `POC_BACKUP_PORT` 修改。测试使用独立临时目录，结束后清理。

## 已实现

### 端侧加密与备份协议

- 每个数据集通过 `createDatasetKeyMaterial(datasetId)` 随机生成一份 256-bit DEK 和独立 256-bit 恢复凭证；同一数据集的全量/增量备份复用该密钥材料，不同数据集之间禁止复用。每个备份使用独立 wrapNonce 包装同一 DEK；全量与多级增量均使用同一恢复凭证完成解密校验。首次全量（sequence=1）可创建密钥材料；增量和后续全量检查点必须显式传入同一份 keyMaterial。
- 使用 AES-256-GCM 包装 DEK 与加密数据块；每块使用随机 96-bit nonce。
- AAD 绑定 dataset_id、backup_id、sequence、parent_backup_id、backup_type、chunk_index、schema_version 和算法套件。
- Manifest 只包含协议字段、密文哈希、块大小、父备份 ID 和被包装的 DEK；不包含备份明文和恢复密钥。
- Manifest 区分 full/incremental；增量必须引用同数据集、序号连续的已提交父备份。HTTP Server 验证完整父链，覆盖全量到多级增量。
- 恢复前验证协议版本、密文哈希、分块数量/序号与 AEAD；恢复失败不替换现有本地数据。
- 提供 `restoreBackupChain` 与 `applyIncremental`：从全量根向前加载多级增量，按 upsert/delete 操作还原快照；新全量检查点可作为新的恢复根，缩短后续恢复链。
- 当前 PoC 页面只在当前浏览器页面会话内持有数据集 DEK；尚未实现本地安全持久化、跨页面恢复密钥材料和设备迁移。

### HTTP 服务端与断点续传

- 独立 Node HTTP Mock Server；服务端以原子写入方式持久化 `state.json`，密文分块单独落盘。
- 服务端不提供解密接口；不保存恢复密钥或备份明文。自动化检查状态文件和密文分块均不包含测试明文/恢复密钥。
- 上传支持缺块查询、断点续传、同块幂等重传、幂等键冲突拒绝、密文哈希校验。
- 上传会话过期后可使用原幂等键重新初始化，但不复用旧分块。
- 服务重启后可恢复未完成上传会话并继续上传；测试覆盖重启后的恢复往返。

### 授权、下载与清除

- 服务端签发数据集范围授权票据，绑定 `backup:read`、`backup:write`、`backup:clear`、`ticket:revoke` 等权限范围及过期时间；服务端仅持久化票据哈希。
- 支持票据主动撤销、过期和跨数据集/权限范围隔离。
- 下载使用短时应用层票据 URL；服务端只持久化票据哈希，票据过期或清除后拒绝访问。
- 清除墓碑先持久化，再撤销该数据集授权、下载票据、上传会话和幂等引用，最后删除密文文件。
- 如果删除过程中服务进程退出，重启时会根据墓碑继续清理未完成的密文文件。
- 清除与上传完成并发时墓碑优先；清除后晚到上传请求不能使数据集复活。

## 关键限制（不得误读为安全验收）

- HTTP Server 是本地 PoC，不是生产部署架构；尚未验证多实例一致性、生产数据库事务、对象存储、真实网络断连和高并发压力。
- 下载 URL 是应用层短时票据路由，不是云对象存储预签名 URL；真实对象存储授权和撤销仍待验证。
- 增量目前由调用方提供增量负载并验证父链，不是本地数据库差异计算；检查点已能建立新的恢复根，但旧备份物理清理/父链压缩策略尚未实现。
- 恢复凭证是随机高熵密钥的 Base64 展示，不是最终用户友好恢复口令；KDF、恢复凭证格式、密钥生命周期和设备迁移流程待安全评审。
- 尚未完成威胁模型、密码学评审、生产密钥托管/轮换策略、服务端日志审查和真实网络故障注入。
- 本 PoC 只提供协议和状态语义验证起点，不能替代密码学审查、威胁建模或正式安全评审。
