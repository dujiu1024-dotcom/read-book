# PoC C：EPUB / PDF / TXT 导入与原文定位

独立阅读引擎 PoC，不依赖数据库、备份或生成任务 PoC。固定版本：Node 22.12.0、epubjs 0.3.93、pdfjs-dist 6.5.438、fflate 0.8.2、Playwright 1.65.0、Vite 7.2.2。

## 运行

```bash
cd poc/book-ingestion
npm install
npx playwright install chromium
npm run dev
npm test
npm run build
```

## 固定样本

`src/fixtures.js` 可重复生成 3 个 EPUB、3 个 PDF、3 个 TXT 样本；测试时记录 SHA-256。样本均为自建虚拟内容，无版权文本。

## 当前实现

- EPUB：读取元数据、导航目录、spine 章节文本；按章节首段生成 CFI 候选；提取图片 src/alt 与脚注文本。
- PDF：PDF.js 解析物理页码、文本项和页内坐标；按 y/x 坐标生成基础阅读顺序，并对跨页重复页眉/页脚做启发式过滤；印刷页码不自动推断。
- TXT：UTF-8 严格解码，失败时尝试 GB18030；固定样本已包含真实 GB18030 编码字节，生成段落起止字符偏移。
- Citation：每章/每页/每段生成定位记录，点击可展示引用文本与定位。
- 文件字节和解析结果存入独立 IndexedDB；刷新后可确认已导入条目仍在。
- PDF.js 使用独立 Worker；EPUB 当前解析流程仍有主线程工作，尚未完成大文件 UI 阻塞测试。

## 尚未通过的验收项

- 每次导入均计算 SHA-256 并作为内容寻址 ID；9 个固定样本哈希已固化在 fixtures.sha256.json，自动化测试逐个比对，避免样本内容静默漂移。
- EPUB 图片/脚注已提取，CFI 已按章节生成候选；复杂目录、跨文件资源路径、真实阅读器中的 CFI 回跳与定位精度仍需人工复核。
- PDF 双栏顺序与重复页眉/页脚采用坐标启发式，尚未覆盖复杂版式、脚注/图表语义和扫描件 OCR；启发式结果必须人工抽样验证。
- TXT GB18030 固定样本已提供真实编码字节夹具并纳入自动化断言；仍需增加更多编码混合、BOM 和异常字节样本。
- 引用回跳目前显示定位元数据与引用片段，不是最终排版阅读器中的精确滚动定位。
- 尚未完成损坏文件、超大文件、刷新后重新解析、离线缓存和性能基准。
- 不把解析成功等同于正文完整或定位正确；必须人工抽样对照原文件。

该 PoC 不决定最终阅读器选型，不构成正式导入服务。
