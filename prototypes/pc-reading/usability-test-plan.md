# PC 窄屏阅读原型可用性任务计划

## 测试边界

原型只使用内置模拟数据。测试重点是用户能否保持“先看原文、再讨论”的连续过程，以及临时查看/复习是否会意外改变主线。

## 典型任务

| ID | 用户任务 | 观察点 | 成功标准 |
|---|---|---|---|
| U01 | 阅读当前原文，折叠后继续讨论，再展开回看 | 原文与讨论顺序、折叠状态可发现性 | 原文始终在讨论上方；折叠不改变主线 |
| U02 | 临时查看第二章，再回到当前主线 | 临时查看标识、返回动作 | 返回后仍是原主线单元 |
| U03 | 复习上一单元，再回到当前内容 | 复习是否影响主线 | 主线游标不变 |
| U04 | 向上阅读历史消息时发送新消息 | 新消息是否强制滚动 | 用户在历史位置时不被拉到底部 |
| U05 | 发送消息、停止生成、模拟失败并重试 | 用户消息保存状态、状态反馈 | 用户输入不丢；停止/失败/重试状态可区分 |
| U06 | 未讨论当前单元时点击继续 | 是否未经确认跳过 | 出现略读确认；取消则留在当前单元 |
| U07 | 在临时查看内容中发言，再回主线点击继续 | 临时讨论是否误标主线已讨论 | 仍需确认当前主线是否略读 |
| U08 | 调整视口宽度和浏览器缩放 | 水平溢出、输入区可操作性 | 360–430 CSS px 与宽屏无核心操作溢出 |

## 测试方式

- 自动化浏览器测试：验证 DOM 状态、交互和响应式溢出。
- 产品走查：按 U01–U08 逐项操作，记录真实观察、完成时间、误操作和用户原话。
- 真实用户测试尚未执行前，不得将自动化测试描述为用户研究结论。
